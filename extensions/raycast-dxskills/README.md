# DxSkills Raycast Extension (D-Mode)

> **Cognitive Scaffolding at the Speed of Thought.**  
> Built for spatial thinkers, non-linear ideators, and systems builders.

---

## ⚡ Features

1. **Compile Clipboard with D-Mode (`d-mode-compile`):**
   - Ingests raw brainstorms, fast typing fragments, and voice dictations directly from your clipboard.
   - Silently corrects common typographical slips without condescending feedback.
   - Extracts a bold Bottom Line Up Front (BLUF) and structured Markdown table.
   - Produces a crisp, collegial action draft with zero em dashes and zero corporate fluff.
   - 1-click paste back to Slack, Gmail, Linear, Obsidian, or VS Code.

2. **Insert Architecture Diagram (`d-mode-diagram`):**
   - Quick-search library of modular Mermaid.js templates (System Architecture, Strategy Flywheel, Curriculum Roadmap, State Machine, Decision Tree).
   - Instant paste as code block into Markdown, GitHub PRs, or Notion.

---

## 🛠️ Local Development & Installation

### Prerequisites
- Node.js v18+ and npm.
- Raycast desktop application (macOS or Windows).

### Install Locally
```bash
# Clone or navigate to the extension directory
cd extensions/raycast-dxskills

# Install dependencies
npm install

# Run in development mode inside Raycast
npm run dev
```

Once running, search for **"Compile Clipboard with D-Mode"** in Raycast to trigger the speed-of-thought compiler on your active clipboard.
