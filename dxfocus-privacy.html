Privacy Policy for DxFocus

01. Overview and Core Philosophy

DxFocus is an offline-first assistive reading application engineered for dyslexic, ADHD, and non-linear spatial thinkers. The application ingests text clippings and web articles through Android system share actions and text selection menus, applying local cognitive formatting such as focus anchor bolding, spatial card chunking, and text-to-speech audio.

✓ Offline-First: All functions work without an internet connection by default.
✓ Local Device Custody: All saved text, articles, and reading notes stay in your private on-device SQLite database.
✓ Zero Monetization of Data: DxFocus does not sell, rent, monetize, or broker personal data.
✓ Zero Trackers: DxFocus contains zero advertising SDKs, zero behavioral analytics frameworks, and zero telemetry trackers.

02. Information Collection and Processing

2.1 Personal Identity Information

DxFocus does not require account registration, login credentials, email addresses, phone numbers, or real-world names to function. You can install and use DxFocus with complete anonymity.

2.2 Ingested Reading Content and Clippings

When you share text or articles into DxFocus using the Android Share Sheet (android.intent.action.SEND) or the floating text selection menu (android.intent.action.PROCESS_TEXT), that content is processed and stored strictly within the app-private SQLite database on your device via the Android Room persistence library. This content is never uploaded to remote analytics servers or analyzed for behavioral profiling.

2.3 Quick-Capture Notes

Notes captured during reading are associated with their respective reading items and card indices. All note data resides strictly within local device storage.

2.4 Web Article Fetching

When you share a web URL (HTTP or HTTPS) to DxFocus, the application uses an on-device HTTP client (OkHttp) to download the webpage HTML directly from the target publisher server. The application then parses readable prose on-device using an embedded HTML parser (Jsoup), stripping away advertisements, navigation scripts, and tracking code.

  • Direct connection: requests occur directly between your device and the destination website.
  • No proxy servers, scraper farms, or intermediary collection nodes.
  • No record of requested URLs is transmitted to the developer or any third party.

2.5 Analytics and Advertising Data

DxFocus contains zero third-party advertising SDKs, zero behavioral analytics frameworks (such as Google Analytics for Firebase, Adjust, AppsFlyer, or Facebook SDK), and zero telemetry trackers.

03. Device Permissions

DxFocus requests only normal-level Android permissions that are automatically granted at install time. The application requests zero dangerous or sensitive runtime permissions.

Permission Technical Name Operational Purpose
Internet Access android.permission.INTERNET Downloads webpage HTML when you share a web URL for article extraction.
Network State android.permission.ACCESS_NETWORK_STATE Checks whether an active internet connection exists prior to initiating article download.
Permissions DxFocus Does NOT Request: No location (ACCESS_FINE_LOCATION), no camera/microphone (CAMERA, RECORD_AUDIO), no contacts (READ_CONTACTS), no shared external storage permissions (MANAGE_EXTERNAL_STORAGE). All local records live strictly inside the sandboxed private data directory.

04. On-Device Cognitive Engines

All cognitive processing algorithms run 100% on your local device:

1. Focus Anchors (Visual)

Calculates word onset bolding in memory using deterministic Kotlin string algorithms as an optional visual reading preference.

2. Spatial Card Chunker

Segments text into 120-180 word swipeable cards using local sentence scoring to prevent cognitive fatigue.

3. System Text-to-Speech

Uses the standard Android system Text-to-Speech API. Speech is synthesized locally by your device engine without retaining audio streams.

05. Optional Cloud Synchronization

DxFocus is architected to operate fully without cloud connectivity. A modular cloud synchronization hook is provided for users or organizations who choose to enable multi-device synchronization:

  • Disabled by Default: Cloud synchronization is completely inactive in the default application build.
  • Opt-In Configuration: Activates only when built with a valid, authenticated configuration file pointing to a user-controlled Google Cloud Firestore database.
  • Transport Security: All network traffic uses TLS 1.3 encryption.
  • Automatic Fallback: If network access is unavailable, the application operates purely offline with zero disruption.

06. Data Retention, Control, and Deletion

You maintain complete ownership and control over your data:

  • In-App Deletion: You can delete any saved article or note directly within the app. Deletion immediately and permanently purges the record from the local SQLite database.
  • Complete Reset: Clear application data at any time via Android Settings (Settings > Apps > DxFocus > Storage & cache > Clear storage).
  • Uninstallation: Uninstalling DxFocus permanently removes the application sandbox and all stored records.

07. Regulatory Compliance & Children Privacy

GDPR Compliance: DxFocus adheres to Privacy by Design and Privacy by Default (Article 25 GDPR). Because all reading content is kept on-device, you retain sole custody of your data. No international data transfers occur during normal operation.

CCPA / CPRA: DxFocus does not sell, share, rent, or disclose personal information to commercial third parties.

Children Privacy: DxFocus is a general-audience assistive reading utility. The application is not directed toward children under 13 (or 16 in the European Economic Area) and does not knowingly collect personally identifiable information from children.
